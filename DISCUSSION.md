## Why React As Front-End UI

I was thinking about future usage and expansion. Because there is a lot of loading/reloading of the app page when submitting a new "feedback" and updating the dashboard realtime, you don't to have to reload the whole page if it's not required.  So if the widged is embedded somewhere, it won't affect all other surrounding parts fo the page other than the connect feedback dashboard

## Exact 3-Hr Session

I wanted to be fair and dedicate exactly 3-Hrs to the project and leave it wherever it ends after the session ended. I was able to accomplish the basic requirements of the application. To save some time, I decided to store any "feedback" and "user info" to JSON. I was more concerned about the functionality of the API and the UI that would make calls to the API. 

I was not able to implement the Export of data to a CSV or add AI-powered analysis.  But I don't think it would have taken too long to get those added. I would need to do some research on free AI apis to see what could be implemented.

*** I do want to not it took roughly 15-30 min to setup my environment how I wanted with installs and whatnot since I wasn't sure what to expect.
